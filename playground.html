    The Sum of Degrees Theorem

    Add up the degrees of all the vertices and you always get exactly twice the number of edges, because each edge has two ends. Draw anything you like and compare the "sum of degrees" box with 2 × |E|. A complete graph on n vertices has n(n−1)/2 edges, so n(n−1)/2 minus |E| is the number of pairs of vertices that are not adjacent.

    Chromatic number

    A proper colouring gives joined vertices different colours. The fewest colours that can work is the chromatic number χ(G). A clique is a set of vertices that are all joined to each other, so a clique of k vertices needs k different colours, and χ(G) is at least the size of the biggest clique. A colouring that uses n colours is called an n-colouring. A complete graph on n vertices needs n colours. To colour by hand, start with the vertex of highest degree, give as many other vertices as you can the same colour (never two joined vertices), working from highest to lowest degree, then repeat with a new colour. The button does exactly this, but the method is not guaranteed to use the fewest colours. For a planar graph, which can be drawn with no edges crossing, 4 colours are always enough (the Four Colour Theorem).
